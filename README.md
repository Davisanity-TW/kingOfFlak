# 彈幕生存遊戲

工單 02：完整追蹤彈幕與難度時間表。使用 TypeScript、原生 Canvas 與 Vite，無執行階段框架。以方向鍵移動，接觸子彈結算，按「再飛一次」重設本局。

地圖為 800 × 600，飛機約 20 × 20、最高速度每秒 240。電腦版開局 40 顆、初速 40，每 5 秒增加 20 顆並加速 10；手機版開局 40 顆、初速 40，每 5 秒增加 10 顆並加速 10。數量上限 160 顆、速度上限每秒 240。飛機輪廓約 16 × 16，子彈半徑 2。前 5 秒不追蹤，第 5 秒起以每秒最多 12 度追蹤。

## 工單 04：暫停與恢復

飛行中或開局倒數時，可按 Esc 或「暫停飛行」。視窗失焦、頁面切到背景或手機轉直向也會自動暫停；回到畫面後不會自行開局，必須按「繼續飛行」，重新倒數 3 秒才恢復。暫停與倒數不計入存活時間，也不推進子彈、生成或加速；鍵盤與搖桿輸入會清空。

本機執行 `npm run dev`，開啟 http://127.0.0.1:5174/ 測試本輪版本。可按住方向鍵後按 Esc，確認秒數與彈幕凍結；繼續後鬆手應停在原位。手機橫放操作搖桿後轉直向，再轉回橫向，應先看到暫停畫面，主動繼續後才重新倒數。死亡後「再飛一次」應回到 0.0 秒與 40 顆開局。

2026-11-06：24 項單元測試、10 項 Chrome 瀏覽器測試、型別檢查、格式檢查與正式建置通過。自動化測試涵蓋狀態及時間邊界；Chrome 手機模擬涵蓋旋轉與恢復後結算／重玩。瀏覽器測試採單一 worker，避免測試視窗互搶焦點觸發自動暫停。真實手機、Safari 與長時間效能驗收留待工單 05；工單 04 尚未發布至線上。

## 工單 09：結算排行榜與弱網處理

開始前可在「開始飛行」下方按「查看排行榜」，不必先輸入暱稱；結算後入口位於「修改暱稱」下方。排行榜由玩家點擊後以彈出視窗覆蓋遊戲，返回、Esc 與點擊背景均保留原畫面。結算視窗另提供「再飛一次」，清除本局顯示並重新倒數。

死亡後保留秒數、子彈數與畫面，自動提交一次再讀共同前 50 名；每次開啟或重讀取得最新榜，不重送。視窗保留完成時的本局摘要，以唯一局次、原名、模式與成績匹配本局列，入口與該列顯示「新入榜」，存活時間下方顯示紅色閃爍小字 `New Record`（減少動態效果設定下為靜態）。被擠出前 50 名時移除標記並保留本機摘要。資料庫僅保留榜內 50 筆；未入榜明示未收錄，不保留全量歷史。上傳回應遺失但榜內確認本局，可判定已收錄；沒有找到則維持上傳狀態未確認。離線／服務錯誤清空榜列，仍能重玩；不補傳離線局次，舊局回應不得覆蓋新局。

本機先 `npm run api:migrate:local`，以 `npm run api:dev` 啟動服務；另一終端以 `VITE_LEADERBOARD_URL=http://127.0.0.1:8787 npm run dev` 啟動遊戲。若 5174 已有舊開發伺服器，先停止再啟動，或將 `.env.example` 複製為未追蹤的 `.env.local`。未設定 API 時，結算會明示本局未上傳。

開啟 [本機遊戲](http://127.0.0.1:5174/)，先測試空白暱稱查看與返回，再完成一局查看本局摘要、入榜標記及重玩。手機橫放確認視窗與表格可捲動，返回和再飛一次可到達；關閉 API 後重讀應清空表格並提示錯誤。追加驗證見 [彈出視窗驗證](docs/task09-popup-validation.md)，原側欄紀錄保留於 [工單 09 驗證](docs/task09-validation.md)。2026-11-06 正式發布本輪功能（程式提交 `b151ba1`），Worker 與資料保留遷移同步更新；正式網址的 `version.txt` 可確認 Pages 部署提交。實機玩家驗收仍待完成。
