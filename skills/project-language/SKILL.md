# 專案語言規範

- 本專案所有文件的標題與敘述均使用繁體中文，包括 README、規格、設計、操作說明、開發指引與 skill 文件。
- 程式碼註解與文件字串使用英文。
- Git commit 的標題與內文使用英文。
- 程式識別字、指令、路徑、設定鍵、API 名稱與必要的技術專有名詞保留原文；文件中的程式碼範例也遵循英文註解規則。
- 完成修改前，檢查本次新增或修改的文件、註解與 commit 訊息是否符合以上規範。
