## 已收斂流程

- 入口位置與開啟時機：開始按鈕下方及修改暱稱下方，各由玩家點擊開啟，不自動彈出。
- 本局成績識別：沿用單局唯一識別，不以暱稱認人。以原名、模式及整數十分之一秒確認回傳紀錄與本局一致。首次開局前沒有本局摘要；結算後關閉再開或編輯下一局暱稱，仍顯示原本已完成的本局，不將草稿暱稱套用到舊成績。
- 新入榜語意：依最新前 50 名判定，入口按鈕與對應榜單列皆可標示；回應遺失時沿用 Q5。重新讀榜後若本局已被擠出前 50 名，依 Q1 移除入榜標記，仍保留本局摘要。
- 重玩：關閉並清除視窗內容、建立下一局已指定；保留既有暱稱驗證、開局倒數與舊回應不覆寫新局規則。

規劃訪談階段僅修改文件；後續實作沿用現有後端與排行榜排序，發布另依使用者指示。尚未涉及難以逆轉的技術選擇，不另建立 ADR。Q1–Q5 均已由使用者確認，沒有待決策分支。

## 狀態與網路處理

| 情境 | 本局摘要與標記 |
| --- | --- |
| 首次開局前查看 | 只顯示所選裝置榜，不提交、不顯示本局摘要，不要求輸入暱稱。 |
| 死亡後提交／讀榜中 | 結算保留原秒數、子彈數及畫面；摘要呈現處理中，不預先標新入榜。 |
| 成功提交，最新榜含本局 | 顯示已上傳／已收錄、新入榜；強調本局列，保留摘要。 |
| 提交回覆未收錄，最新榜不含本局 | 顯示「本局未入前 50 名，未收錄。」；保留本局摘要，不查榜外名次。 |
| 曾確認收錄，最新榜不含本局 | 顯示已收錄過／目前未入前 50 名；被擠出的資料已移除，仍保留本機摘要。 |
| 提交逾時／回應遺失，最新榜含相同局次與完整成績 | 由榜單確認已收錄，顯示新入榜，不繼續顯示上傳不確定。 |
| 提交逾時／回應遺失，最新榜沒有本局 | 保留「成績上傳狀態未確認」；可能未入榜而未收錄，或曾入榜後被擠出，不推定失敗或未入榜。 |
| 服務明確拒絕提交 | 顯示未上傳，不以一般讀榜成功改成上傳成功。 |
| 讀榜失敗 | 顯示既定離線／服務故障提示，清空榜列，不顯示仍有效的新入榜標記；保留本局成績及已知提交狀態。 |
| 原本入榜，重新讀榜後被擠出 | 移除新入榜標記與列強調，保留摘要並依已知收錄證據顯示未入前 50 名。 |

死亡自動提交仍只有一次。若提交尚未完成便打開視窗，先顯示目前提交狀態；等待同一提交完成或逾時後讀榜，不另行提交。每次開啟及手動重讀皆使用新請求，不沿用已完成的舊榜快取；進行中的讀取須取消或忽略過時回應，避免重複並行或倒序覆蓋。僅關閉視窗不取消已送出的成績提交；任何回應都不能自動重開視窗。

開啟視窗時限制焦點與鍵盤／搖桿操作於視窗；Esc 只執行返回，不觸發底層遊戲行為。點擊內容、表格或捲動區不得被當作點擊背景。提供可辨識的視窗標題、返回按鈕名稱，關閉後焦點回到原入口。手機橫向提供可捲動內容，返回與再飛一次皆可到達，不由彈出視窗伸展擠壓地圖。

按「再飛一次」關閉視窗，清空榜列、本局摘要、入榜標記及錯誤提示，隔離舊局網路回應，再依既有流程建立新局；保留原暱稱及裝置模式。重玩本身不清空資料庫；榜外資料依前 50 名保留政策移除。開始前視窗只提供返回及 Esc／背景關閉，不提供重玩。
