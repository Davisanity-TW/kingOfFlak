# 工單 09 追加規劃：排行榜彈出視窗

狀態：2026-11-06 兩輪需求訪談已確認，追加規劃完成，尚未開始實作。依使用者要求採用 `grill-with-docs`，結合 `grilling` 與 `domain-modeling` 逐輪確認；原工單 09 的側欄排行榜實作為 `7d6f7d6`，尚未發布。原版測試結果不得當作新需求驗收。

## 使用者已明確指定

- 遊戲開始前，在「開始飛行」下方提供「查看排行榜」按鈕。
- 遊戲結束後，在「修改暱稱」下方提供排行榜按鈕；玩家點擊後才開啟排行榜。
- 排行榜以彈出視窗覆蓋遊戲主畫面，取代直接展開側欄榜單的呈現。
- 玩家按「再飛一次」時，清除排行榜彈出視窗並重新開始遊戲。
- 本局入榜時標示「新入榜」，排行榜畫面特別標示本局成績。
- 延續共同前 20 名、同名多局、模式後綴、台北時間、5 秒逾時、只重試讀榜與不補傳等已確認規則。

## 第一輪已確認決策

- Q1：以本局唯一局次是否出現在最新成功讀取的前 20 名判定「新入榜」，不以暱稱或同分匹配；讀榜失敗不宣稱入榜。
- Q2：排行榜上方固定顯示本局暱稱、秒數與上傳狀態；未入榜仍保留摘要。入榜時額外強調對應列；未入榜、未上傳、狀態未確認分開顯示。
- Q3：新增「返回」按鈕，與關閉鍵、Esc、點擊背景一致，關閉視窗並回到原畫面，不開局。開始前無須有效暱稱即可查看；結算後視窗另提供「再飛一次」。視窗開啟時阻擋底層開始與搖桿操作，關閉保留暱稱及結算內容，焦點回原入口。

## 第二輪已確認決策

- Q4：死亡後沿用自動上傳並讀榜，結算入口按鈕即可顯示「新入榜」標記；只在點擊時開視窗。每次開啟與手動重讀再取得最新榜單，但不重送成績。開始前只在開啟時讀榜。
- Q5：上傳逾時或回應遺失，但讀榜找到完全相同局次與成績時，以榜單確認已收錄並標示新入榜；若未找到，維持「成績上傳狀態未確認」，不推定失敗或未入榜。

## 已收斂流程

- 入口位置與開啟時機：開始按鈕下方及修改暱稱下方，各由玩家點擊開啟，不自動彈出。
- 本局成績識別：沿用單局唯一識別，不以暱稱認人。以原名、模式及整數十分之一秒確認回傳紀錄與本局一致。首次開局前沒有本局摘要；結算後關閉再開或編輯下一局暱稱，仍顯示原本已完成的本局，不將草稿暱稱套用到舊成績。
- 新入榜語意：依最新前 20 名判定，入口按鈕與對應榜單列皆可標示；回應遺失時沿用 Q5。重新讀榜後若本局已被擠出前 20 名，依 Q1 移除入榜標記，仍保留本局摘要。
- 重玩：關閉並清除視窗內容、建立下一局已指定；保留既有暱稱驗證、開局倒數與舊回應不覆寫新局規則。
- 技術與驗收：本文件作為工單 09 追加驗收依據，區分既有自動化與新視窗測試；正式發布仍依使用者授權。

本輪不改程式、不發布、不建立新後端或改排行榜排序。尚未涉及難以逆轉的技術選擇，不另建立 ADR。Q1–Q5 均已由使用者確認，沒有待決策分支。

## 狀態與網路處理

| 情境 | 本局摘要與標記 |
| --- | --- |
| 首次開局前查看 | 只顯示共同榜，不提交、不顯示本局摘要，不要求輸入暱稱。 |
| 死亡後提交／讀榜中 | 結算保留原秒數、子彈數及畫面；摘要呈現處理中，不預先標新入榜。 |
| 成功提交，最新榜含本局 | 顯示已上傳／已收錄、新入榜；強調本局列，保留摘要。 |
| 成功提交，最新榜不含本局 | 顯示未入前 20 名；保留本局摘要，不查詢前 20 名以外的名次。 |
| 提交逾時／回應遺失，最新榜含相同局次與完整成績 | 由榜單確認已收錄，顯示新入榜，不繼續顯示上傳不確定。 |
| 提交逾時／回應遺失，最新榜沒有本局 | 保留「成績上傳狀態未確認」；可能已收錄但不在前 20 名，不推定失敗或未入榜。 |
| 服務明確拒絕提交 | 顯示未上傳，不以一般讀榜成功改成上傳成功。 |
| 讀榜失敗 | 顯示既定離線／服務故障提示，清空榜列，不顯示仍有效的新入榜標記；保留本局成績及已知提交狀態。 |
| 原本入榜，重新讀榜後被擠出 | 移除新入榜標記與列強調，保留摘要並依已知收錄證據顯示未入前 20 名。 |

死亡自動提交仍只有一次。若提交尚未完成便打開視窗，先顯示目前提交狀態；等待同一提交完成或逾時後讀榜，不另行提交。每次開啟及手動重讀皆使用新請求，不沿用已完成的舊榜快取；進行中的讀取須取消或忽略過時回應，避免重複並行或倒序覆蓋。僅關閉視窗不取消已送出的成績提交；任何回應都不能自動重開視窗。

開啟視窗時限制焦點與鍵盤／搖桿操作於視窗；Esc 只執行返回，不觸發底層遊戲行為。點擊內容、表格或捲動區不得被當作點擊背景。提供可辨識的視窗標題、返回與關閉名稱，關閉後焦點回到原入口。手機橫向提供可捲動內容，返回與再飛一次皆可到達，不由彈出視窗伸展擠壓地圖。

按「再飛一次」關閉視窗，清空榜列、本局摘要、入榜標記及錯誤提示，隔離舊局網路回應，再依既有流程建立新局；保留原暱稱及裝置模式。不清空資料庫或移除已收錄成績。開始前視窗只提供返回／關閉，不提供重玩。
